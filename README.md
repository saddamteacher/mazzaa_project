# MAZZAA — экспортный B2B-сайт

Двуязычный (RU/EN) сайт бренда острых чипсов MAZZAA (QOSIMOV GROUP): каталог, анкета дилера,
региональные прайс-листы, калькулятор оптового заказа, отправка заказов и передача лидов в Bitrix24.

## Что реализовано (этап 1 по ТЗ)

| Раздел ТЗ | Реализация |
| --- | --- |
| Языки | RU и EN с адресами `/ru/…`, `/en/…`, переключатель, `hreflang`. Новый язык — строка в `LANGUAGES` + миграция |
| Главная | Видео/огонь в шапке, 3D-параллакс чипсов при прокрутке, три кликабельных баннера, о компании, кнопка «Стать дистрибьютором» |
| Каталог | 14 позиций в форматах 40/50/100/150 г, карточки с характеристиками коробки; цены скрыты до анкеты |
| Анкета дилера | Поля по ТЗ, согласие на обработку данных, защита от спама, UTM-метки, персональная ссылка доступа |
| Прайс-листы | Отдельная цена каждого товара для каждой страны и валюты, скрытие позиций, история изменений, скачивание Excel/PDF |
| Калькулятор | Стоимость, вес, объём, паллеты, загрузка контейнеров 20′/40′ (по габаритам коробки и лимиту веса), КП в PDF/Excel |
| Заказ | Цены фиксируются на сервере в момент отправки, страница подтверждения, передача в CRM |
| Bitrix24 | Лид при регистрации (без дублей), задача менеджеру со сроком по рабочим часам, заказ в существующий лид/сделку, уведомления, контроль просрочки, очередь с повторами и журналом ошибок |
| Маркетинг | Раздел с материалами по типам, скачивание файлов только для зарегистрированных дилеров |
| Реклама | GTM / GA4 / Google Ads / Meta Pixel с Consent Mode, события `generate_lead`, `view_price_list`, `calculator_use`, `order_submit`, `click_whatsapp`, `click_telegram`; посадочные страницы по странам `/ru/markets/kz/` |
| Админ-панель | Товары, цены, валюты, страны, фото, баннеры, маркетинг, переводы, пользователи и роли, заявки и журнал CRM, журнал изменений |
| Техника | Адаптивная вёрстка, sitemap.xml, robots.txt, HTTPS-настройки, блокировка подбора пароля, политика конфиденциальности и cookie |

Этап 2 (не входит): личный кабинет с историей заказов и повторными закупками, расширенная 3D-раскладка контейнера,
дополнительные языки, онлайн-оплата.

## Технологии и почему

- **Python 3.13 + Django 5.2 LTS** — готовая админ-панель с ролями и журналом изменений, поддержка до 2028 года,
  легко найти разработчика для сопровождения.
- **PostgreSQL** в продакшене (SQLite локально), **WhiteNoise** для статики, **gunicorn**.
- Без сборщиков фронтенда: чистые HTML/CSS/JS — страницы быстрые, нечему ломаться.
- Excel — `openpyxl`, PDF — `reportlab`.

## Запуск локально

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export DEBUG=1
python manage.py migrate
python manage.py init_site --demo      # справочники и линейка; --demo добавляет ДЕМО-габариты и ДЕМО-цены
python manage.py createsuperuser
python manage.py runserver
python manage.py test tests            # 22 теста по сценариям приёмки
```

Сайт: http://localhost:8000/, админ-панель: http://localhost:8000/admin/.

## Публикация

В репозитории есть `render.yaml` (Render: веб-сервис, PostgreSQL, диск для файлов, cron). Подойдёт и любой VPS:
`./build.sh`, затем `gunicorn config.wsgi:application`, плюс cron `python manage.py process_crm_queue` каждые 5 минут.
Переменные окружения — в `.env.example`. Домен, хостинг и база должны быть оформлены на QOSIMOV GROUP.

Резервные копии: ежедневный `pg_dump` базы (на Render — встроенные бэкапы) и копия папки `MEDIA_ROOT`.

## Инструкция администратора

- **Цены**: «Каталог и цены → Цены по странам», фильтр по стране справа, цена правится прямо в списке.
  Галочка «Скрыть» убирает товар из прайса страны. Каждое изменение попадает в «Историю изменения цен».
  Цены не пересчитываются по курсу автоматически.
- **Новая страна или валюта**: «Валюты» → «Страны и рынки» → добавить цены. Там же — менеджер Bitrix24 для страны
  и включение посадочной страницы.
- **Товары**: название и описание на двух языках, фото, количество в коробке, габариты, вес брутто, паллета.
  Объём считается из габаритов. Пока у товара нет фото, показывается рисованная упаковка.
- **Главная**: «Баннеры главной» и «Настройки сайта» (тексты о компании, контакты, видео в шапке, логотип).
- **Доступ к ценам**: «Настройки сайта → Доступ к ценам» — автоматически или после одобрения менеджером
  (одобрение: «Дилеры» → выбрать → «Открыть доступ к ценам»).
- **Переводы**: «Тексты интерфейса» — любой текст сайта можно заменить на каждом языке.
- **Сотрудники**: «Пользователи» + группы «Контент-менеджер», «Менеджер цен», «Менеджер продаж».
- **Аналитика**: идентификаторы GTM / GA4 / Google Ads / Meta Pixel / Search Console — в «Настройках сайта».
- **Заявки и CRM**: «Дилеры», «Заказы», «Журнал передачи в Bitrix24» (статус, ошибка, кнопка «Повторить передачу»).

## Интеграция с Bitrix24

1. В Bitrix24: *Разработчикам → Другое → Входящий вебхук*, права **CRM (crm)**, **Задачи (tasks)**, **Чат и уведомления (im)**.
2. Адрес вебхука записать в переменную окружения `BITRIX24_WEBHOOK_URL` (в код и репозиторий не попадает).
3. В «Настройках сайта» указать ID менеджера по умолчанию, ID руководителя продаж, срок реакции и рабочие часы;
   в «Странах» — менеджера для каждой страны.

| Событие | Что делает сайт | Методы REST |
| --- | --- | --- |
| Анкета | Ищет лид по телефону; если нет — создаёт (контакты, страна, город, компания, язык, источник, UTM) | `crm.duplicate.findbycomm`, `crm.lead.add` |
| Новый лид | Задача «Связаться с новым потенциальным дилером MAZZAA», срок по рабочим часам, руководитель — наблюдатель | `tasks.task.add` |
| Заказ | Комментарий с составом заказа в лид (или в сделку, если лид конвертирован), сумма, уведомление и задача менеджеру | `crm.lead.get`, `crm.deal.list`, `crm.timeline.comment.add`, `crm.lead.update`, `im.notify.system.add`, `tasks.task.add` |
| Просрочка | Уведомление руководителю продаж, если задача первого контакта не закрыта в срок | `tasks.task.get`, `im.notify.system.add` |

Каждая заявка сначала сохраняется в базе сайта, затем отправляется. При сбое — до 12 повторов с нарастающей паузой
(cron `process_crm_queue`), ошибка видна в журнале. Пока вебхук не задан, заявки копятся в очереди и уйдут после подключения.

Стадии воронки («Новый лид с сайта» … «Успешная сделка / отказ») и отчёты по странам, источникам и менеджерам
настраиваются в самом Bitrix24: сайт передаёт для них страну, источник `WEB` и UTM-метки.

## Что нужно заменить перед запуском

- **Демо-цены и демо-габариты коробок** (`init_site --demo`) — вымышленные, только для проверки калькулятора.
- Количество упаковок в коробке для 150 г — не задано («уточняется»).
- Фото упаковок, видео в шапке, текст политики конфиденциальности, условия поставки (EXW/FCA), e-mail и Telegram.
